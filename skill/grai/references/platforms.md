# Platforms: limits, hashtags, posting times, ads

Checked on 2026-10-16 against the platforms' help, developer and ad-spec pages, plus three posting-time studies. Platforms change these values. When the user plans to buy ads, tell them to check the platform's spec page.

## How to use the posting times

- All study times are local to the audience. Give them in the audience time zone from the settings, and name the study.
- The studies disagree. Give the window from the first study in the table, and add one line when another study points to a different window.
- Always end with: "Your own analytics beat any benchmark."
- If you have web search, look for a newer study. Say if it differs.

Studies: Sprout Social 2026 (2 billion engagements, Nov 2025 to Feb 2026). Buffer 2026 (52 million posts, 2024 to 2025). Hootsuite 2025 (1 million posts, time-zone agnostic).

## LinkedIn

| Item | Value |
|---|---|
| Post | 3,000 characters. "See more" cuts at about 210 characters on desktop and about 140 on mobile (not published by LinkedIn) |
| Hashtags | 0 to 3, at the end, as topic labels. They give no reach boost |
| Times | Sprout: Tue to Thu, 11:00 to 17:00. Buffer: Wed to Fri, 15:00 to 20:00. Hootsuite: Tue and Wed, 04:00 to 06:00. All agree: weekdays beat weekends |
| B2B (Sprout) | Tech: Tue to Thu, 10:00 to 14:00. Financial services: Tue to Thu, 10:00 to 15:00. Retail: Wed and Thu, 10:00 to 14:00 |
| Document or carousel | 1 PDF, PPT or DOC per post, up to 300 pages |
| Images | Up to 20 per post. 1080 px wide. Ratio from 3:1 to 4:5. Several images show at 4:5 at most |
| Poll | Question 140 characters. 2 to 4 options, 30 characters each. Default 1 week |
| Video | Up to 15 minutes for members, 10 minutes for Pages |
| Article | Title about 150 characters. Use an article for anything over 3,000 characters |
| Collaborative post | Up to 5 co-authors (rolled out July 2026) |
| Collaborative articles | Retired. Do not suggest them |
| Showcase Page | Up to 25 per company Page. Same post types as the Page |

Ads: Sponsored Content, single image. Introductory text 150 recommended (max 3,000). Headline 70 recommended (max 200). Description 100 recommended (max 300). CTA options: Apply, Download, View Quote, Learn More, Sign Up, Subscribe, Register, Join, Attend, Request Demo. Thought Leader Ads boost a member's own post as it is: text, single image, video, article, newsletter. Not documents, polls or multi-image posts.

## X

| Item | Value |
|---|---|
| Post | 280 characters (free). Paid plans allow longer posts. Each link uses 23 characters |
| Hashtags | 0 to 2 (X's own advice: no more than 2) |
| Times | Sprout: Tue to Thu, 12:00 to 18:00. Buffer: Tue to Thu, 09:00 to 11:00. Hootsuite: Wed to Fri, 09:00 to 11:00 |
| Media | Up to 4 images, or 1 GIF, or 1 video. X does not publish organic image sizes. Use 1:1 or 16:9 |
| Poll | 2 to 4 options, 25 characters each, 5 minutes to 7 days. No image in a poll |
| Video | Up to 140 seconds (free) |
| Thread | Part 1 must work alone. No official limit on the number of parts |

Ads: promoted post. Copy 280 characters, minus 23 per link. Website card headline 50 recommended (max 70). Image 1.91:1 or 1:1.

## Facebook

| Item | Value |
|---|---|
| Post | No verified limit. Write it like LinkedIn: the first 2 lines carry the post |
| Hashtags | No official number. Use few or none |
| Times | Sprout: Tue and Wed, 12:00 to 20:00. Buffer: weekdays, 08:00 to 12:00. Hootsuite: Tue, 09:00 |
| Video | Every video is now a Reel, with no length limit |
| Image | 4:5 (1440 x 1800) |

Ads: Meta Feed. Primary text 50 to 150 characters. Headline 27.

## Instagram

| Item | Value |
|---|---|
| Caption | 2,200 characters. About 125 characters show before "more" |
| Hashtags | Up to 5. This is a platform cap since December 2025. Put them in the caption |
| Times | Sprout: Tue and Wed, 12:00 to 19:00. Buffer: Wed 12:00 and 18:00, Thu 09:00. Hootsuite: Mon, 15:00 to 21:00 |
| Carousel | Up to 20 slides, one orientation for all. 4:5 (1080 x 1350) |
| Reel | Up to 3 minutes. 9:16 (1080 x 1920) |
| Collab post | One post on both profiles. The co-author must accept. Plan for up to 3 co-authors |
| Alt text | Up to 1,000 characters |

Ads: Meta Feed. Primary text 125 characters. Headline 40.

## Threads

| Item | Value |
|---|---|
| Post | 500 characters. A text attachment can carry up to 10,000 more |
| Hashtags | One topic tag per post, 1 to 50 characters |
| Times | Buffer: Tue to Thu, 07:00 to 12:00. Hootsuite: Tue, 08:00. Evenings perform worst |
| Carousel | 2 to 20 images or videos |
| Poll | 2 to 4 options, 25 characters each, text posts only |
| Links | Up to 5 per post |

Ads: no verified spec. Do not write Threads ads.

## Reddit

| Item | Value |
|---|---|
| Title | 300 characters. State the point in the title |
| Body | 40,000 characters |
| Hashtags | None. Reddit has no hashtags |
| Times | One study only (redditapis.com 2026): Sunday, 15:00 to 21:00 US Eastern. Convert to the audience time zone. The subreddit matters more than the hour |
| Rules | Each subreddit sets its own rules. Tell the user to read them before posting |
| Tone | Give value in the post itself. No sales tone. A link is optional |

Ads: promoted post. Headline 100 recommended (max 300, 80 is safer). Free-form body: 3 to 6 lines. Poll posts cannot be promoted.

## TikTok

| Item | Value |
|---|---|
| Caption | 2,200 characters |
| Photo post | Up to 35 photos. Title 90 characters |
| Hashtags | No official number. Use a few topical ones |
| Times | Sprout: Tue to Thu, 13:00 to 18:00. Buffer: Sun 09:00, Mon 13:00, evenings. Hootsuite: Thu, 07:00 to 11:00. The studies disagree strongly |
| Video | 9:16 |

Ads: Spark Ad boosts the organic post as it is. Its caption comes from the post. About 100 characters show before "See more". Other in-feed ads: text up to 100 characters, with no links, @ or hashtags.
