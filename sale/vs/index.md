# grai vs. Alternatives: Honest Category & Architecture Comparisons (2026)

> **Last verified against public pricing and source architecture:** 2026-11-12
> **Canonical URL:** https://grai.page/vs/

**Direct Answer:** `grai` is a local-first HTML5 voice workbench ($79/yr Solo or $99/mo or $790/yr Agency) that extracts a quantitative Voice DNA profile from 5 to 20 real posts. It audits every draft in your browser against 8 structural rules and a burstiness floor (`CV >= 0.32`). It does not schedule posts or connect to your LinkedIn account.

## 3. Shipped Pre-Built Kit vs. Custom Source Build

1. **Shipped Pre-Built Kit (`grai.html` in the ZIP): Local App with Direct API Connections Blocked by Default (Copy-Paste Mode)**
   The pre-built `grai.html` file ships with a Content Security Policy (`default-src 'none'; style-src 'unsafe-inline'; font-src data:; img-src data:; script-src 'unsafe-inline'; connect-src 'none'; object-src 'none'; base-uri 'none'`) that allows inline styles and inline scripts (plus `data:` fonts and images) while blocking direct API connections (`connect-src 'none'`) from the page. Out of the box, it runs in Copy-Paste ("Any AI") mode: it builds a compact prompt under 1,800 characters that you copy into your existing Claude or ChatGPT web tab (or Gemini), then paste back into `grai` for local verification.
2. **Custom Source Build (`source/src/app.html` + `scripts/build.py`): Direct BYOK API & Local Ollama Mode**
   If you want direct browser-to-API calls (Anthropic or OpenAI, plus Gemini and OpenRouter) or local Ollama (`http://localhost:11434`) / LM Studio (`http://localhost:1234`), edit the `connect-src` directive in `source/src/app.html` and rebuild `grai.html` with `python3 scripts/build.py` (included in the kit). Direct requests go from your browser to your configured endpoint (subject to standard browser CORS rules on `file://`), never through a `grai` application backend.
